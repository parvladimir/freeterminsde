# Urologie Marl Termin-Monitor v3

Красивые и компактные Telegram-уведомления.

## Формат сообщений

- Первый запуск: компактный список свободных дней и количество терминов.
- Новый ранний термин до 01.08.2026: отдельная громкая тревога.
- Обычные изменения: короткое тихое сообщение.
- Исчез целый день: отдельный заметный блок.
- Изменилось время: показываются только добавленные и исчезнувшие часы.

## Обновление

Для обновления существующего репозитория достаточно заменить `monitor.py`.

Чтобы снова увидеть стартовое сообщение, можно дополнительно заменить `state.json` на файл из архива.
