# Urologie Marl Termin-Monitor v2

Монитор проверяет календарь каждые 10 минут.

Он находит первую доступную дату и показывает все свободные даты и время на один месяц вперёд от неё. При первом запуске присылает полный список. При любом изменении присылает обновлённый список.

Когда исчезает целый день, сообщение выглядит так:

`❌ День ушёл: 14.09.2026`

Когда исчезает отдельное время, появляется новый день или новое время, бот также сообщает об этом отдельно. Срочное уведомление о любом новом термине раньше 01.08.2026 сохранено.

Для обновления старой версии замените файлы `monitor.py`, `requirements.txt`, `.github/workflows/check.yml`, `README.md` и `state.json`.
